# 原始数据与派生数据字段说明

本目录所有实验均为100轮、batch64、seed42–46。CSV使用UTF-8编码，部分含BOM；Python读取推荐 `encoding='utf-8-sig'`。

## 1. 训练与原始结果

`training_results/runs.csv` 每行一个seed，共5行：

| 字段 | 含义与单位 |
|---|---|
| seed | 随机种子整数 |
| best_epoch | 最高验证准确率首次出现的epoch |
| best_val_digit_accuracy | 最佳验证数字准确率，百分数 |
| digit_test_loss | 选中checkpoint的测试集平均交叉熵 |
| digit_test_accuracy | 选中checkpoint的数字测试准确率，百分数 |
| training_time_seconds | 原训练程序累计耗时，包含该seed训练、验证、最终测试与保存等开销 |
| checkpoint_path | 相对本交付目录的权重路径 |

`training_results/summary.json` 和summary.csv给出上述指标的mean、std、min、max。std采用五seed样本标准差，ddof=1。

`training_results/seed_*/history.csv` 每seed100行，记录seed、epoch、train_loss、train_digit_accuracy、val_loss、val_digit_accuracy、learning_rate、elapsed_seconds。损失为按样本加权的平均交叉熵，准确率为百分数，elapsed_seconds为本seed训练开始后的累计秒数。训练使用train模式，验证使用eval模式。

`digit_confusion_matrix.csv` 的行由true_label标识，pred_0至pred_9各列为预测到对应数字的**计数**，不是比例；每个seed的矩阵总计10000。

`metrics.json` 的digit_per_class_accuracy是各真实类别的Recall百分数；它不是Precision。

## 2. 扩展分类与训练动态分析

`analysis_data/per_seed_results.csv` 补充epochs、batch_size、optimizer_updates，以及最佳epoch和第100轮的训练/验证指标。名称以_percent结尾的值均为百分数。

- optimizer_updates：78200，按ceil(50000/64)×100计算，不包括仅评估的batch。
- first_epoch_val_accuracy_ge99：该seed首次验证准确率达到99%的轮次。
- min_val_loss：100轮中最低验证交叉熵；它不是本实验的checkpoint选择指标。

`per_class_metrics_all_seeds.csv` 共50行，按seed和digit标识：

- support：真实属于该类别的测试图片数量。
- correct：该类别预测正确数量。
- errors：support减correct。
- precision_percent：TP/(TP+FP)×100。
- recall_percent：TP/(TP+FN)×100。
- f1_percent：该类Precision与Recall的调和平均数×100。

`per_class_summary.csv` 对每一类别分别汇总五seed，recall_std_percentage_points是百分点尺度的样本标准差。

`confusion_pairs_all_seeds.csv` 只列非零非对角项，true_digit为真实标签，predicted_digit为错误预测标签，count为张数，true_class_percent=count/support×100。

`training_history_all_seeds.csv` 汇集五个history文件，共500行，可用于统一绘制曲线。

## 3. 固定seed42的完整测试预测

`predictions/seed42_test_predictions.csv` 共10000行：

- dataset_index：官方MNIST测试集的零起始索引，0至9999。
- true_digit、predicted_digit：真实与预测数字。
- correct：0或1。
- predicted_probability：softmax中预测类别的分数。
- p_0至p_9：十个类别的softmax概率，总和约为1。

这些概率未经过额外校准。完整预测仅用于模型评估和错误分析，不用于重新选择checkpoint。

`seed42_misclassified_images.npz` 只包含58张错误样本。images为像素张量，dataset_indices对应原测试索引；同时保存真实标签、预测标签和预测类别概率。错分展示图按索引升序取前24张。

## 4. embedding与顺序分析

`figures/embedding_seed42/embeddings.npz` 包含：

| 数组 | 形状或意义 |
|---|---|
| embeddings | 2000×128，BaseModel特征 |
| labels | 2000个真实数字标签，每类200个 |
| selected_indices | 对应官方测试集的零起始索引 |
| tsne_coordinates | 2000×2的t-SNE坐标 |
| pca_projection | 2000个方向处理后的PC1投影值 |

`embedding_samples.csv` 将测试索引、digit、tsne_x、tsne_y、pca_projection逐行导出。

`class_projection.csv` 按数字给出PC1投影的count、mean、std、median、min、max。这里std为每类200张图片投影值的样本标准差，与五seed运行标准差是不同统计量。

`embedding_metrics.json`：

- raw_spearman_rho：未经符号处理的PC1与数字标签秩相关。
- orientation_flipped：是否因raw rho<0而翻转PC1。
- spearman_rho：方向处理后的相关，本次约0.317265。
- spearman_p_value：Spearman检验的名义p值，不表示效果大小。
- pca_explained_variance_ratio：PC1解释方差比例，0至1，本次约0.230887。
- discovered_order：按各数字的平均投影值排序，不是模型分类标签映射。

这些指标仅代表预定seed42，不能当作五seed统计。

## 5. 路径与可复现记录

交付文件中的checkpoint_path、checkpoint、source_csv、config_path已改为相对本交付目录的路径，数值统计保持不变。provenance.json记录训练代码版本、环境和实验标识；source_snapshot保存关键源文件供核对；sha256.json用于检查文件内容是否变化。
